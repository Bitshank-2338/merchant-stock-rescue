# Submission QA checklist

- [ ] Run `npm install`, `npm test`, and `npm run build` successfully.
- [ ] Confirm the README lists exactly five tools and matches the implementation.
- [ ] Confirm pre-approval `commit_transfer` returns `HUMAN_APPROVAL_REQUIRED`.
- [ ] Confirm UI approval changes the proposal to approved and commit returns a receipt.
- [ ] Confirm rejected, duplicate, stale, invalid-ID, invalid-quantity, and insufficient-stock paths are represented honestly.
- [ ] Test the registration harness in a real browser; do not describe this as manual Chrome Inspector testing.
- [ ] Verify Chrome flag and HTTPS/localhost notes before recording.
- [ ] Capture proposal, approved, and committed screenshots with relative paths.
- [ ] Replace TODO repository, live HTTPS, and video URLs.
- [ ] Review the public repository for secrets before publishing.
