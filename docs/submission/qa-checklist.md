# Submission QA checklist

- [x] Run `npm install`, `npm test`, and `npm run build` successfully.
- [x] Confirm the README lists exactly five tools and matches the implementation.
- [x] Confirm pre-approval `commit_transfer` returns `HUMAN_APPROVAL_REQUIRED`.
- [x] Confirm UI approval changes the proposal to approved and commit returns a receipt.
- [x] Confirm rejected, duplicate, stale, invalid-ID, invalid-quantity, and insufficient-stock paths are represented honestly.
- [x] Test the registration harness in a real browser; do not describe this as manual Chrome Inspector testing.
- [ ] Verify Chrome flag and HTTPS/localhost notes before recording.
- [x] Capture dashboard, proposal, approved, committed, and mobile screenshots with relative paths.
- [x] Add and verify the public repository and live HTTPS URLs.
- [x] Review the public repository for secrets before publishing.
- [x] Render and verify a narrated 2:24, 1080p demo video.
- [x] Upload the rendered MP4 to YouTube as public and add its URL.
- [ ] Run the optional final Chrome Inspector confidence check before the final Devpost submission.
